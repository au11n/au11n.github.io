I completed the course "[Linux Operating System Administration](https://stepik.org/course/114923/)" on Stepik.
It's a very small, "dry" course for beginners.

Only the following topics are covered:
- navigating directories,
- creating / deleting files and directories,
- connecting via ssh.

The following topics are not really touched upon:
- working with users and permissions,
- working with processes and daemons,
- working with network settings and security.
